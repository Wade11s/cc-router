这一版新增升级后自动弹出的更新内容说明，以后每次升级都能直接在 app 里看到这一版改了什么；托盘菜单加上了代理状态和常用快捷方式；实时路由页换成「手绘速写本」风格；厂商信息跟随界面语言，并新增 Requesty 服务商与智谱 Z.ai 国际版端点。升级后默认行为不变。
更新内容说明是这一版才有的功能，所以最后一节附上 6.0.0 的主要变化。

## 新功能
- **更新内容说明**：升级后第一次打开窗口会自动弹出这一版的更新内容，只弹一次；中间跳过了几个版本的话，错过的版本会一起列出。弹窗顶部可以在中文、English、日本語之间切换，默认跟随界面语言。关掉后点侧栏底部的礼花（「更新内容」）可以再次打开，也能翻看更早的版本。网页界面不会自动弹出，只保留侧栏入口。
- **托盘菜单显示状态和快捷方式**：托盘菜单新增版本号、代理运行状态与监听地址、订阅可用数（点击进入订阅页），以及「实时路由」「请求日志」快捷入口、「复制 Claude Code 环境变量」（Windows 上复制 PowerShell 写法）、「检查更新…」（有新版本时直接显示版本号）和「开机自动启动」勾选框。状态变化时菜单就地刷新。
- **实时路由页换成「手绘速写本」风格**：页面改为卡片布局；路由图里客户端画成便签、上游厂商画成行李吊牌，随窗口宽度自动缩放。名下订阅全部停用的厂商显示为灰色，不再当成故障标红。
- **厂商信息跟随界面语言**：内置厂商的名称、说明、兼容性提示和端点名称在英文、日文界面下显示对应语言，订阅列表里的厂商名也跟着切换（用量小票仍显示创建订阅时的名称）。
- **新增 Requesty 服务商**（#48）：内置 Requesty 的 Anthropic 兼容端点，另有欧洲区域端点，两者共用同一个 Key。
- **智谱新增 Z.ai 国际版端点**：新增 Z.ai 的 Coding Plan 订阅与按量付费两个端点，需要使用 Z.ai 的 API Key，与 open.bigmodel.cn 的 Key 不通用。
- **订阅列表显示区域**：订阅管理页的厂商名后显示区域标签（中国 / 全球 / 欧洲），本地与自定义订阅不显示；小米、Kiro 的欧洲端点标记为「欧洲」。

## 修复
- **切换端点后刷新模型列表查错地址**：内置订阅切换到另一个区域的端点后，刷新模型列表时仍会去查旧端点的域名，换成新区域的 API Key 后会因此失败。

## 其他
- 移除已停止运营的神马中转 API（whatai）；已有订阅不受影响，新建订阅时不再列出。
- OpenRouter 图标在浅色背景下改用单色版，避免看不清。

## 6.0.0 回顾
- **「手绘速写本」外观**：配色与官网一致，侧栏、卡片、按钮、弹窗等都换成手绘外形，浅色和暗色两套。
- **终端界面 cc-router-tui**（默认关闭）：不开窗口也能在终端里管理 cc-router。打开方式：设置 → 安全与访问 → 终端界面。
- **工具调用统计**：请求日志记录模型调用了哪些工具，统计页新增工具调用指标卡和 Top 10 工具卡；只存工具名，不存调用参数和返回内容。
- **请求详情弹窗重新排版**：新增路由路径与用量两栏，能看到每次请求走了哪个订阅、真实模型，以及耗时、输入、输出、缓存读写。
- **自定义厂商自动获取模型列表**（#44）：保存前就能探测上游的模型列表。
- **数据库体积上限真正生效**：超过上限（默认 500 MB）会从最旧的请求日志和事件开始删除。
- **后端返回的文字跟随界面语言**：测试连接结果、订阅的最近错误、余额卡片在英文、日文界面下不再显示中文。
