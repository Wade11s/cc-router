今回のバージョンでは、アップデート後にリリースノートが自動で表示されるようになり、何が変わったかをアプリ内ですぐ確認できます。トレイメニューにプロキシの状態とよく使うショートカットが加わり、リアルタイムルーティング画面は「手描きスケッチブック」のデザインになりました。プロバイダ情報が UI の言語に従うようになり、Requesty プロバイダと Zhipu の Z.ai 国際版エンドポイントが加わりました。既定の動作は変わりません。
リリースノートはこのバージョンで追加された機能のため、最後に 6.0.0 の主な変更をまとめています。

## 新機能
- **アップデート後のリリースノート**：アップデート後に初めてウィンドウを開くと、そのバージョンのリリースノートが一度だけ表示されます。途中のバージョンを飛ばした場合は、見逃したバージョンもまとめて表示されます。上部のタブで 中文・English・日本語 を切り替えられ、既定は UI の言語です。閉じた後はサイドバー下部のクラッカー（「リリースノート」）から開き直せ、以前のバージョンも見られます。Web UI では自動表示されず、サイドバーの入口だけがあります。
- **トレイメニューに状態とショートカットを表示**：トレイメニューにバージョン、プロキシの稼働状態と待ち受けアドレス、利用可能なサブスクリプション数（クリックでサブスクリプション画面を開きます）が表示されるようになりました。さらに「リアルタイムルーティング」「リクエストログ」へのショートカット、「Claude Code の環境変数をコピー」（Windows では PowerShell 形式）、「更新を確認…」（新しいバージョンがあるとバージョン番号を表示）、「起動時に自動実行」のチェックボックスが加わりました。状態が変わるとメニューはその場で更新されます。
- **リアルタイムルーティング画面が「手描きスケッチブック」デザインに**：画面をカード構成に改め、ルーティング図ではクライアントを付箋、上流プロバイダを荷札として描き、ウィンドウ幅に合わせて自動で拡大縮小します。配下のサブスクリプションがすべて無効なプロバイダは、障害扱いの赤ではなくグレーで表示されます。
- **プロバイダ情報が UI の言語に追従**：内蔵プロバイダの名前、説明、互換性の注意、エンドポイント名が英語・日本語の UI ではそれぞれの言語で表示され、サブスクリプション一覧のプロバイダ名も切り替わります（利用レシートはサブスクリプション作成時の名前のままです）。
- **Requesty プロバイダを追加**（#48）：Requesty の Anthropic 互換エンドポイントを内蔵し、EU エンドポイントも用意しました。どちらも同じ Key を使います。
- **Zhipu に Z.ai 国際版エンドポイントを追加**：Z.ai の Coding Plan サブスクリプションと従量課金の 2 つのエンドポイントを追加しました。Z.ai の API Key が必要で、open.bigmodel.cn の Key は使えません。
- **サブスクリプション一覧にリージョンを表示**：サブスクリプション画面のプロバイダ名の後ろにリージョンのタグ（中国 / グローバル / EU）を表示します。ローカルとカスタムのサブスクリプションには表示しません。Xiaomi と Kiro のヨーロッパ向けエンドポイントは EU と表示されます。

## 修正
- **エンドポイント切り替え後のモデル一覧更新が誤ったアドレスを参照**：内蔵サブスクリプションを別リージョンのエンドポイントに切り替えた後、モデル一覧を更新すると旧エンドポイントのドメインを参照し続け、新しいリージョンの API Key では失敗していました。

## その他
- サービスを終了した 神马中转 API（whatai）プロバイダを削除しました。既存のサブスクリプションには影響せず、新規作成時の選択肢から外れます。
- OpenRouter のアイコンは、明るい背景では読みやすいようモノクロ版を使います。

## 6.0.0 のおさらい
- **「手描きスケッチブック」の外観**：配色を公式サイトと揃え、サイドバー、カード、ボタン、ダイアログなどを手描きの形にしました。ライトとダークの 2 種類があります。
- **ターミナル UI cc-router-tui**（既定で無効）：ウィンドウを開かずにターミナルから cc-router を管理できます。設定 → セキュリティとアクセス → ターミナル UI で有効にします。
- **ツール呼び出し統計**：リクエストログにモデルが呼び出したツールを記録し、統計画面にツール呼び出しの指標カードと Top 10 ツールのカードを追加しました。保存するのはツール名だけで、引数や結果は保存しません。
- **リクエスト詳細ダイアログのレイアウトを刷新**：ルートと使用量の 2 つの欄を追加し、各リクエストがどのサブスクリプションと実際のモデルを通ったか、所要時間、入力、出力、キャッシュの読み書きを確認できます。
- **カスタムプロバイダのモデル自動検出**（#44）：保存前に上流のモデル一覧を取得できます。
- **データベースサイズ上限が実際に機能するように**：上限（既定 500 MB）を超えると、古いリクエストログとイベントから削除します。
- **バックエンドの文言が UI の言語に追従**：接続テストの結果、サブスクリプションの直近のエラー、残高カードが、英語・日本語の UI で中国語表示されなくなりました。
