このバージョンでは、テーマの切り替え（手描き、クラシック、Win2000）と設定のエクスポート / インポートを追加しました。プロキシのポートやプロトコルなどの設定を変更したあと、アプリ全体を再起動しなくても設定ページからプロキシを再起動できるようになりました。アップグレード後のデフォルトの動作は変わらず、画面は引き続き手描きテーマです。

## 新機能
- **テーマ**：3 つのテーマから選べます。手描き（デフォルト。公式サイトと同じスケッチブック風）、クラシック（リニューアル前のシンプルな見た目）、Win2000（レトロな Windows 2000 風）です。設定 → 一般 → 外観で切り替えるほか、サイドバー下部のテーマボタンで順に切り替えることもできます。
  - サイドバー下部にカラーモードのボタンを追加しました。「システムに従う → ライト → ダーク」の順に切り替わります。
  - クラシックテーマでは、リアルタイムルーティングのページがリニューアル前の全幅レイアウトとルーティング図に戻ります。
  - Win2000 テーマでは、Windows / Linux のウィンドウのタイトルバーも Windows 2000 風に描画されます。macOS ではシステムの信号機ボタンをそのまま使います。
- **設定のエクスポート / インポート**：設定 → バックアップと移行で、サブスクリプションと仮想モデルの設定をエクスポートし、別のマシンや再インストール後にインポートできます。リクエストログと統計は含まれません。
  - エクスポート時に API Key とプロキシのアクセストークンを含めるかどうかを選べます。この部分は設定したパスワードで暗号化され、パスワードは復元できません。ChatGPT / Kiro のログイン情報はどの場合もエクスポートされないため、新しいマシンで再度ログインしてください。
  - インポート前に、各サブスクリプションが追加されるかスキップされるかをプレビューできます。このマシンに既にあるもの、再ログインが必要なもの、検証に通らなかったものは、理由を表示したうえでスキップされます。
  - キーなしでインポートしたサブスクリプションは無効の状態で追加され、サブスクリプション一覧に「API Key 未入力」と表示されます。
  - 初回起動時、最初のサブスクリプションを追加するページからも「バックアップからインポート」できます。
  - Web UI からはキーを含まない設定のみエクスポートできます。
- **プロキシサービスの再起動**：プロトコル、ポート、リッスンアドレス、リクエストボディの上限、HTTP/2 を変更したあと、設定 → プロキシ → プロキシサービスで「プロキシサービスを再起動」を押すと、アプリを再起動せずに反映されます。処理中のリクエストは中断されません。
  - 新しいポートが使用中の場合は次の空きポートを使い、クライアントで使う新しいアドレスを表示します。新しい設定で起動できなかった場合は元の設定に戻して動作を続けます。
  - HTTPS 証明書の再生成や、証明書に追加する IP / ドメインの変更もすぐに反映され、再起動は不要になりました。

## 修正
- **エラーメッセージが `[object Object]` と表示される**：一部の操作が失敗したとき、メッセージに `[object Object]` としか表示されませんでした。具体的な原因を表示するようにしました。
- **日本語の画面で漢字が中国語の字形で表示される**：ページの言語が中国語に固定されていたため、日本語の画面で漢字が中国語の字形で描画され、Web UI ではブラウザに翻訳を勧められていました。画面の言語に従うようにしました。

## その他
- 設定ページに「Web & TUI」と「バックアップと移行」の 2 つのタブを追加しました。Web UI とターミナル UI の設定は「セキュリティとアクセス」から「Web & TUI」に移動しました。
- 「情報」ページと初回起動ページの免責事項に、cc-router は独立したサードパーティのオープンソースプロジェクトであり、Anthropic とは関係がなく、Claude / Claude Code の公式アプリでもないことを追記しました。
- Tauri を 2.12 にアップグレードし、セキュリティアドバイザリに対応するため rustls を更新しました。有効にしているログイン時の自動起動には影響ありません。ソースからビルドするには Rust 1.90 以降が必要です。
