这一版新增界面主题切换（手绘、经典、Win2000）和配置导入导出；代理服务的端口、协议等设置改完后可以直接在设置页重启代理，不用再重启整个 app。升级后默认行为不变，界面仍是手绘主题。

## 新功能
- **界面主题**：新增三套主题可选——手绘（默认，与官网一致的速写本风格）、经典（改版前的简洁样式）、Win2000（复古的 Windows 2000 风格）。在设置 → 通用 → 外观切换，也可以点侧栏底部的主题按钮轮换。
  - 侧栏底部新增明暗模式按钮，按「跟随系统 → 浅色 → 暗色」轮换。
  - 经典主题下实时路由页恢复为改版前的通栏布局与路由图。
  - Win2000 主题在 Windows / Linux 上会把窗口标题栏也画成 Windows 2000 样式，macOS 保留系统的红绿灯按钮。
- **配置导入导出**：在设置 → 备份与迁移导出订阅与虚拟模型配置，到另一台机器或重装后导入。请求日志和统计不包含在内。
  - 导出时可以选择包含 API Key 与代理访问令牌，这部分用你设置的密码加密；密码无法找回。ChatGPT / Kiro 的登录凭据任何情况下都不导出，需要在新机器上重新登录。
  - 导入前先预览每条订阅会被新增还是跳过：本机已有的同一条订阅、需要重新登录的订阅、没通过校验的订阅都会跳过并说明原因。
  - 不含密钥导入的订阅会先停用，并在订阅列表里标出「待填写 API Key」。
  - 首次使用时，添加第一个订阅的页面也能直接「从备份导入配置」。
  - 网页界面里只能导出不含密钥的配置。
- **重启代理服务**：修改协议、端口、监听地址、请求体上限或 HTTP/2 后，在设置 → 代理 → 代理服务点「重启代理服务」即可生效，不用重启 app，正在进行的请求不会被中断。
  - 新端口被占用时自动顺延，并提示客户端要改用的新地址；新配置启动失败会自动恢复原配置继续运行。
  - 重新生成 HTTPS 证书、修改证书附加的 IP / 域名后立即生效，也不再需要重启。

## 修复
- **报错提示显示为 `[object Object]`**：多处操作失败时提示框里只有 `[object Object]`，现在显示具体原因。
- **日文界面的汉字按中文字形显示**：页面语言以前固定标成中文，日文界面里的汉字会用中文字形渲染，网页界面还会被浏览器提示翻译；现在跟随界面语言。
