これはメジャーリリースです。デスクトップ app が公式サイトと同じ「スケッチブック」外観に変わり、新しいターミナル UI cc-router-tui を使えばウィンドウを開かずに cc-router を管理できます。リクエストログと統計ではツール呼び出しを記録するようになり、データベースサイズ上限は名ばかりの設定から実際に効く安全網になりました。既存の動作はデフォルトでは変わらず、ターミナル UI はデフォルトで無効です。

## 新機能
- **スケッチブックの外観**: 象牙紙、インク、テラコッタの配色で、ライト・ダーク両パレットとも ccrouter.app と同じ値を使っています。サイドバーには手描きのアイコンが 11 個並び、右端は手描きの波線になりました。ロゴは手描きで新しく描き直され、app アイコンも一式再生成されています。カード、ボタン、タグ、入力欄、スイッチ、セグメントコントロール、テーブル、ダイアログ、タブはすべて手描き風の形になり、ページタイトルにはテラコッタの二重線の下線が付きました。app には Instrument Sans / Newsreader / JetBrains Mono / Caveat のラテン文字サブセットが同梱されており、中国語と日本語のテキストは引き続きシステムフォントを使います。
- **ターミナル UI cc-router-tui（デフォルトで無効）**: ターミナルから稼働中の cc-router を管理できます。設定 → セキュリティとアクセス → ターミナル UI で有効化してください。
  - タブは 5 つ: 総覧、サブスクリプション、仮想モデル、リアルタイムルーティング、リクエストログ。
  - サブスクリプション: 有効化・無効化、接続テスト、モデルの再取得、残高の再取得、各スロットのモデルと思考強度の変更ができます。サブスクリプションの新規作成（内蔵プロバイダ、または 5 種類のプロトコルに対応したカスタムプロバイダ、いずれもモデル自動検出付き）と削除も可能で、削除確認ではそのサブスクリプションを参照しているすべての仮想モデルが一覧表示されます。
  - 仮想モデル: サブスクリプションの並び替え、追加・削除、スケジューリングモードの切り替えができます。
  - リアルタイムルーティング: すべての試行の流れと直近 60 秒分を表示し、一時停止とフィルタが可能です。行の上で ⏎ を押すと、そのサブスクリプションのリクエストログにジャンプします。
  - リクエストログ: ページ送りとフィルタに対応し、各リクエストの詳細も見られます。
  - インターフェースは中国語・英語・日本語に対応し、デスクトップ app の言語設定に従います。設定が「システムに従う」の場合は、トレイメニューと同じ方法で言語が決まります。
  - ローカル接続のみを受け付け、Web UI を有効にする必要はありません。
  - 同じ設定カードに「PATH に追加」の行があります。macOS ではシンボリックリンクを作成し、Windows ではインストール先をユーザー PATH に追加し、AppImage では実行ファイルを ~/.local/bin にコピーします。追加後は、どのターミナルでも cc-router-tui と入力するだけで起動できます。
  - `--check` でセルフテストを実行できます。`--no-fx` または `CCR_TUI_NO_FX=1` でアニメーションを無効化できます。配色はターミナルの能力に応じてトゥルーカラー・16 色・無色（NO_COLOR）のいずれかになります。
  - ターミナルは 80×24 以上が必要です。OAuth 認証によるサブスクリプションの新規作成と API Key の変更は、依然としてデスクトップ app で行います。
- **ツール呼び出し統計**: リクエストログに stop_reason、リクエストで提示されたツール数、送信された tool_result の数、返ってきた tool_use の数、呼び出されたツール名が新たに記録されます。保存されるのはツール名だけで、呼び出しの引数や結果は保存されません。すべての上流プロトコルが対象です。統計ページにはツール呼び出しの KPI カードが 2 枚と、Top 10 ツールカードが追加されました（同名のツールでもクライアントが異なれば別々に表示されます）。サブスクリプションのテーブルにはツール列が、リクエスト一覧にはツールのマーカーが追加されました。
- リクエスト詳細ダイアログのレイアウトが一新されました:
  - 上部にステータス、HTTP コード、ストリーミングかどうかに加えて時刻とリクエスト ID を表示し、「すべてコピー」は常に表示されます。
  - ルートの区画が新設され、クライアント → 仮想モデル → サブスクリプション → 実モデル（上流が返したモデル名を含む）を表示します。
  - 使用量の区画が新設され、レイテンシ、入力、出力、キャッシュ読取、キャッシュ書込を表示します。これまでダイアログには Token 数が表示されていませんでした。
  - ツール呼び出し、エラーメッセージ、上流のレスポンス原文がそれぞれ独立した区画になりました。
- **仮想モデルページの「サブスクリプションを追加」ダイアログ**の情報が増えました。各行にプロバイダのロゴ、サブスクリプション名とステータス、プロバイダとエンドポイント（OAuth サブスクリプションの場合はアカウントのメールアドレス)、その仮想モデルで実際に使われるモデル、すでに参照している仮想モデルが表示されます。候補が 6 件を超えると検索ボックスが現れ、フッターに選択件数が表示されます。
- **カスタムプロバイダのモデル自動検出（#44）**: 保存前に上流のモデル一覧を取得できるようになり、この取得処理はデータベースに何も書き込みません。カスタム Anthropic エンドポイントでも同様に使えます。スロットは内蔵プロバイダと同じセレクターを使い、スロットごとの思考強度も設定できます。
- 設定 → 詳細 でデータベースの容量と各テーブルの行数を確認できるようになりました。
- cc-router がすでに起動している状態でもう一度起動すると、新しいプロセスを起動する代わりに既存のウィンドウを呼び出します。

## 修正
- **バックエンドから返る文字列が UI の言語に従うようになりました**: これまで英語・日本語の UI でも、接続テストの結果、サブスクリプションの直近のエラー、残高カードは中国語で表示されていました。Codex 推奨設定内のコメントも三語に翻訳されました。
- **データベースサイズ上限が実際に効くようになりました**。この設定は以前は何もしていませんでした。これからは上限（デフォルト 500 MB）を超えると、まず最も古いリクエストログとイベントから削除され、警告イベントが発行されます。データベースファイルは起動ごとに整理され、上限を 0 にすると機能をオフにできます。イベントテーブルもリクエストログと同じ「ログ保持期間」の設定で削除されるようになりました。
- macOS の Dock アイコンが Apple のアイコングリッドに合わせた余白を持つようになり、Dock や Cmd+Tab で他の app より一回り大きく見えることがなくなりました。

## その他
- どの画面からも使われず、リクエストログと内容が重複していた request 系イベントを削除しました。app のログファイルは 1 日単位でローテーションされ、直近 14 日分が保持されます。
- 内蔵プロバイダの定義が app 本体にコンパイルされるようになり、インストール先のディレクトリに yaml や sql ファイルが含まれなくなりました。
- README の三言語すべてに「ターミナル UI」の節が追加されました。
