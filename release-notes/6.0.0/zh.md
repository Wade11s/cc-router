这是一个大版本：桌面端换上与官网一致的「手绘速写本」外观；新增终端界面 cc-router-tui，不开窗口也能管理 cc-router；请求日志和统计页开始记录工具调用；数据库体积上限从摆设变成真正生效的安全网。升级后默认行为不变，终端界面默认关闭。

## 新功能
- **「手绘速写本」外观**：配色是象牙纸底、墨色、陶土色，浅色和暗色两套都与官网 ccrouter.app 同值。侧栏换成 11 枚手绘图标，右边缘是一条手画的波浪线；Logo 重新描成手绘版，App 图标整套重新生成。卡片、按钮、标签、输入框、开关、分段控件、表格、弹窗、Tab 都改成手绘外形，页面标题下加了陶土色双笔触下划线。安装包自带 Instrument Sans / Newsreader / JetBrains Mono / Caveat 的拉丁子集，中文和日文仍用系统字体。
- **终端界面 cc-router-tui（默认关闭）**：在终端里管理正在运行的 cc-router。打开方式：设置 → 安全与访问 → 终端界面，打开「启用终端界面」。
  - 共五个标签：总览、订阅、虚拟模型、实时路由、请求日志。
  - 订阅：启用 / 停用、测试连接、刷新模型、刷新余额，修改各槽位的模型和思考档位；可以新建订阅（内置厂商，或 5 种协议的自定义厂商，都能自动探测模型），也可以删除（确认时会列出哪些虚拟模型引用了它）。
  - 虚拟模型：调整订阅顺序、增删订阅、切换调度模式。
  - 实时路由：显示每次尝试的流水和最近 60 秒的情况，可以暂停、过滤；在某一行按 ⏎ 会跳到该订阅的请求日志。
  - 请求日志：分页浏览，可过滤，能看每条请求的详情。
  - 界面有中文、英文、日文三种，跟随桌面端的语言设置；设成「跟随系统」时判断规则和托盘菜单一样。
  - 只接受本机连接，不需要打开网页界面。
  - 同一张卡片里有「添加到 PATH」一栏：macOS 建一个符号链接，Windows 加进用户 PATH，AppImage 复制到 ~/.local/bin。之后在任何终端里直接输入 cc-router-tui 就能打开。
  - 支持 --check 自检；--no-fx 或 CCR_TUI_NO_FX=1 关闭动效；按终端能力使用真彩色、16 色或无色（NO_COLOR）。
  - 终端至少要 80×24。新建 OAuth 类订阅、修改 API Key 仍需在桌面端完成。
- **工具调用统计**：请求日志新记录 stop_reason、请求里提供的工具数、tool_result 数、tool_use 数和被调用的工具名。只存工具名，不存调用参数和工具返回的内容。所有上游协议都会采集。统计页新增两个工具调用指标卡、一张 Top 10 工具卡（不同客户端的同名工具分开列）；订阅表加了工具列；请求列表带工具标记。
- 请求详情弹窗重新排版：
  - 顶部显示状态、HTTP、是否流式，以及时间和请求 ID，「复制全部」按钮始终在。
  - 新增路由路径一栏：客户端 → 虚拟模型 → 订阅 → 真实模型（含上游返回的模型名）。
  - 新增用量一栏：耗时、输入、输出、缓存读取、缓存写入。之前弹窗里不显示 token 数。
  - 工具调用、错误信息、上游原文各自单独成区。
- **虚拟模型页「添加订阅」弹窗信息更全**：每行显示厂商 logo、订阅名和状态、厂商与接入地址（OAuth 订阅显示邮箱）、该订阅在当前虚拟模型里实际会用到的模型，以及已被哪些虚拟模型引用。候选超过 6 个时出现搜索框，底部显示已选数量。
- **自定义厂商自动获取模型列表（#44）**：保存前就能探测上游的模型列表，探测过程不会写入数据库。自定义 Anthropic 也支持。槽位改用和内置厂商相同的选择器，可以为每个槽位设置思考档位。
- 设置 → 高级 显示数据库体积和各表的行数。
- 已经开着 cc-router 时再次启动，会直接唤回原来的窗口，不会再开一个实例。

## 修复
- **后端返回的文字跟随界面语言**：之前在英文、日文界面下，测试连接结果、订阅的最近错误、余额卡片仍显示中文。Codex 推荐配置里的注释也改为三语。
- **数据库体积上限真正生效**：这个设置以前不起作用。现在超过上限（默认 500 MB）会从最旧的请求日志和事件开始删除，并发出一条警告事件；每次启动时整理数据库文件；设为 0 表示关闭。事件表现在和请求日志一样按「日志保留天数」清理。
- macOS 的 Dock 图标按 Apple 图标网格留出边距，在 Dock 和 Cmd+Tab 里不再比其他 app 大一圈。

## 其他
- 下线了没有任何界面使用、且与请求日志重复的 request 类事件；应用日志改为每天一个文件，保留 14 天。
- 内置厂商的配置文件编译进程序本体，安装目录里不再附带 yaml / sql 文件。
- README 三语新增「终端界面」一节。
